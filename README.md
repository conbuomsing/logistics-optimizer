# Ứng dụng Tối ưu Logistics Dệt May

Ứng dụng web được phát triển bằng Streamlit để tối ưu hóa việc phân bổ phương tiện vận chuyển cho doanh nghiệp dệt may.

## Tính năng

- Tối ưu phân bổ 5 loại phương tiện vận chuyển:
  - Xe 1.5 tấn
  - Xe 1.9 tấn
  - Xe 3.5 tấn
  - Container 20ft
  - Container 40ft
- Tính toán chi phí cho 2 tuyến đường:
  - Nội Bài
  - Hải Phòng
- Hiển thị kết quả dạng bảng và biểu đồ

## Cài đặt

```bash
pip install -r requirements.txt
```

## Chạy ứng dụng

```bash
streamlit run app.py
```
